# Prompt Engineering Portfolio

This repository showcases my work in **AI prompt engineering**, including **JSON workflows**, **data annotation**, and **structured outputs** for AI applications. It demonstrates how carefully designed prompts can guide AI models to automate tasks and produce actionable, structured results.

---

## Projects Overview

### 1. Customer Support Assistant
Automates customer email handling by:  
- Summarizing complaints  
- Classifying issues (e.g., delivery, product quality)  
- Drafting polite responses  

**Includes:**  
- Problem statement  
- Prompt designs (before/after)  
- Example outputs  
- Testing and iteration notes  

### 2. Research Assistant
Supports academic research by:  
- Summarizing papers  
- Generating research questions  
- Categorizing articles by theme  

### 3. Entrepreneurship Tutor Bot
Provides business guidance by:  
- Explaining entrepreneurship concepts at multiple levels  
- Giving feedback on business ideas  
- Assisting users in refining strategies

## Visual Cheat Sheet

**JSON & Data Annotation Workflow**

![JSON & Data Annotation Workflow](visuals/ai_json_annotation_cheatsheet.png)

Workflow Steps:  
1. **Raw Data** – Text, images, or audio  
2. **Data Annotation** – Label sentiment, category, and key quotes  
3. **Structured JSON** – Standardized format for AI input/output  
4. **AI Model Input** – Model processes data and produces JSON output  
5. **Business Use** – Dashboards, reports, or applications
